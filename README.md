# JumpDrill

Beat Saber のジャンプ配置を練習するための譜面（ドリル）を作るツールです。
ノーツの配置・速さ・NJS を自由に指定でき、プレイしたリプレイからスイングの再現性を集計します。

パソコンで使う **アプリ（JumpDrill）** と、ゲームの中で使う **MOD（JumpDrillMod）** があります。
どちらも同じドリルを作り、同じ記録を読むので、片方だけでも両方でも使えます。

## ダウンロードとインストール

### アプリ

[Releases](https://github.com/Buri28/JumpDrill/releases) から `JumpDrill-v*.zip` をダウンロードして展開し、`JumpDrillGui.exe` を起動します。
.NET のインストールは不要です（Windows のみ）。

### MOD

アプリの［MOD を入れる］から入れるのが簡単です。見つかった Beat Saber が一覧に出るので、入れる先にチェックを付けて［入れる］を押します。
一覧にない場所は［フォルダを追加...］で選べます。
合う MOD が無い Beat Saber に入れるときは、どのバージョン用の MOD を入れるかを選べます（バージョンが合わない MOD は、正しく動かないことがあります）。

手で入れる場合は、Releases の `JumpDrillMod-v<バージョン>-bs<Beat Saber のバージョン>.zip` を Beat Saber のフォルダに展開してください。

| 項目 | 内容 |
|---|---|
| 対応する Beat Saber | 1.40.8 / 1.44.1 |
| 必要な MOD | BSIPA / BeatSaberMarkupLanguage / SiraUtil / SongCore |
| LeaderboardCore（任意） | 曲選択画面のリーダーボードに記録を表示するのに使います |
| BeatLeader（任意） | 記録したリプレイをゲーム内で再生するのに使います |

### 更新

アプリに新しいバージョンがあると、ボタンに「v*.*.* に更新」と表示されます。押すとアプリを閉じて更新画面を開きます。
作ったドリルや記録はそのまま残ります。

更新のあと、入っている MOD が古い場合は［MOD を更新］と表示されます。

## アプリの使い方

1. グリッドをクリックして、ノーツを置く位置と順番を指定します（右クリックでその手の指定を消します）。「遷移（記法）」欄に[配置の書き方](#配置の書き方)で入力することもできます
2. BPM・切る方向・NJS・クリック音・置き場所を指定します
3. ［生成］を押すと譜面ができます

| ボタン | 内容 |
|---|---|
| 生成 | 指定した譜面を作ります |
| ドリル一括生成 | 練習用の譜面一式（112 本）を作ります |
| ArcViewer でプレビュー | 作った譜面をブラウザで確認します |
| スコア | リプレイを読み込み、譜面ごとの記録を表示します |
| メダル | 一括生成した譜面のメダルと Lv を表示します。マスを選ぶと、その譜面のスコア画面や ArcViewer を開けます |
| MOD を入れる | JumpDrillMod を Beat Saber に入れます |

スコア画面とメダル画面では、どの Beat Saber の記録を見るかを選べます（「すべてのバージョン」または各インストール）。

画面の設定は `%LOCALAPPDATA%\JumpDrill\settings.txt` に保存され、次回の起動時に戻ります。

## MOD の使い方

### Jump Drill 画面

メインメニューの **JumpDrill** ボタンで開きます。

- **Drill**：112 本のドリルのメダルと Lv を一覧で表示します。ドリルを選んで **Play** を押すと練習モードで始まります
- **Other**：自分で作ったドリルを選べます
- **Generate drills**：112 本をまとめて作ります
- 右側に、選んだドリルの記録を表示します

### ドリルを1本作る

曲選択画面の Mods タブにある **JumpDrill** で指定します。

| タブ | 内容 |
|---|---|
| Transition | グリッドでノーツを置く位置と順番を指定します |
| Hand & Direction | 手の使い方、左右反転、切る方向 |
| Timing | BPM・長さ・繰り返す回数・NJS・ジャンプ距離 |
| Click | クリック音とカウントイン |

**Generate** を押すと、専用パック「JumpDrill」に追加され、曲一覧が更新されます。

### 記録

ドリルを選ぶと、曲選択画面のリーダーボードが JumpDrill の表示に切り替わります（LeaderboardCore が必要です）。
ドリル以外の曲に戻ると、それまで見ていたリーダーボードに戻ります。

- 行を選ぶと、そのプレイのスイングの軌道を図で表示します
- 並び順は **Best**（順位）と **Newest**（新しい順）を切り替えられます
- 自動プレイの記録には `AUTO`、曲の速さを変えた記録には `SPEED` と表示されます。どちらも順位とメダルには数えません

MOD は、プレイしたリプレイを `UserData\JumpDrillMod\Replays` にも保存します。BeatLeader が入っていなくても記録が残ります。

## 配置の書き方

グリッドの各マスを次の文字で表します。

```
1 2 3 4
5 6 7 8
9 a b c
```

- 先頭の `R` / `L` で手を指定します（省略すると右手）。`R8b` は、右手で 8 と b を交互に切る配置です
- カンマで区切ると両手を指定できます: `R8b, La1`
- 3か所以上を順に回る配置も書けます: `L194c`
- 位置の後ろに `s` を付けると、そのノーツの矢印を上下左右のいずれかに揃えます: `R4bs`

## 置き場所

アプリの「出力」で選べます。

| 置き場所 | 内容 |
|---|---|
| 専用パック「JumpDrill」・スコア送信なし | 曲一覧に「JumpDrill」というパックとしてまとまります（おすすめ） |
| WIP・スコア送信なし | `CustomWIPLevels` に置きます |
| 通常・スコアが上がる | `CustomLevels` に置きます。スコアが ScoreSaber / BeatLeader に送信されます |
| 手動指定 | 好きなフォルダを指定します |

専用パックと WIP の譜面は、練習モードでのみプレイできます。MOD で作るドリルは、いつも専用パック「JumpDrill」に入ります。

曲名は `[ID] Drill <配置> <切る方向> <BPM> BPM <長さ>` の形式になります。
BPM は片手あたりの速さで、EBPM と同じ値です。ID は配置・速さ・長さから決まるので、同じ指定で作り直しても記録はそのまま引き継がれます。

## ドリル一括生成

14 方向 × 8 Stage の譜面（112 本）をまとめて作ります。各 Stage は右手 10 秒 → 左手 10 秒の構成です（Stage 8 のみ各 30 秒）。

| Stage | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8（30秒） |
|---|---|---|---|---|---|---|---|---|
| BPM | 100 | 150 | 200 | 250 | 300 | 350 | 400 | 350 |
| NJS | 14 | 15 | 16 | 17 | 18 | 19 | 20 | 19 |

方向によって、BPM に次の倍率がかかります。

| 倍率 | 方向（右手） |
|---|---|
| ×1 | `3b` `4b` `8b` `8a` `38` `3c` |
| ×2/3 | `4a` `89` `86` `ca` |
| ×1/2 | `49` `85` `c9` `82` |

再現精度に応じてメダルとして表示されます（🥉 70% / 🥈 80% / 🥇 90% 以上）。
Lv はメダルのポイント（🥉1 🥈2 🥇3）の合計で、最大 336 です。

## スコアの見方

BeatLeader / LocalLeaderboard / JumpDrillMod が保存したリプレイ（`.bsor`）を読み込み、譜面ごとに記録を表示します。
同じプレイが複数の MOD に保存されている場合は、1 件として数えます。

| 指標 | 内容 |
|---|---|
| 再現精度 % | 順位の基準です。再現の値に、譜面どおりに振れたスイングの割合を掛けたものです |
| 再現 /100 | 行きと帰りのスイングが、どれだけ同じ軌道を通っているかを表します（100 点満点） |
| 角度点 / 中心点 | ゲーム本体と同じ計算方法による得点です（100 点満点 / 15 点満点） |
| 打点ずれ | 判定の基準時刻からのずれです（ms、＋は遅れ） |

### 再現と再現精度 % の計算方法

再現は、手ごとに次の手順で計算します。

1. セイバー先端の軌道を、どのノーツからどのノーツへ振ったかで分類します
2. 行きのスイングと帰りのスイングについて、それぞれ平均の軌道を求めます
3. 2 つのノーツを結ぶ線を 20 区間に分け、各区間での行きと帰りの軌道の差を求めます。その二乗平均平方根（RMS）を **往復のずれ**（m）とします。ノーツより外側（振り抜いた先）は計算に含めません
4. 往復のずれを **ノーツ間の距離** で割り、点数に換算します

```
再現 = 100 × (1 − (往復のずれ ÷ ノーツ間の距離) ÷ 0.5)     ※ 0〜100 の範囲に収めます
```

往復のずれが 0（行きと帰りが同じ軌道）なら 100 点、ノーツ間の距離の 50% 以上ずれていれば 0 点です。
スイングは手首を中心に回るため軌道は必ず曲がりますが、行きと帰りが重なっていれば減点されません。

再現はスイングの本数を考慮しないため、少しだけプレイしてやめても高い値になります。
そのため順位には、ミスなどで振れなかった分を差し引いた再現精度 % を使います。

```
再現精度 % = Σ(手ごとの再現 × その手のスイング数) ÷ 譜面のノーツ数（両手の合計）
```

- スイング数は、計算に使えたスイングの本数です（同じ区間を 3 回以上振ったものが対象です）
- 譜面のノーツ数は、リプレイではなく譜面ファイルから数えます。途中でやめた場合も、満点の基準は変わりません
- ミスなしで全ノーツを切り、再現が 100 であれば、再現精度 % も 100 になります

例: 左右 300 ノーツずつの譜面で、左手が再現 70・スイング数 210、右手が再現 90・スイング数 300 の場合

```
再現精度 % = (70 × 210 + 90 × 300) ÷ 600 = 69.5
```
